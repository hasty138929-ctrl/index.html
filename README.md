## 📖 معرفی پروژه
**NutriAI Pro** یک وب‌اپلیکیشن جامع و کاربرپسند برای مدیریت سلامت است که با هدف شخصی‌سازی سبک زندگی سالم طراحی شده است. این پروژه به کاربران کمک می‌کند تا با دریافت برنامه‌های تغذیه‌ای، تمرینی و ماساژ، به اهداف سلامتی خود برسند. دستیار هوشمند (Nutribot) در این اپلیکیشن نقش یک مربی شخصی را ایفا می‌کند.

## ✨ امکانات کلیدی
- **📊 محاسبه‌گر BMI و کالری:** محاسبه دقیق شاخص توده بدنی و نیاز روزانه کالری.
- **🍲 کتابخانه دستور پخت:** بیش از ۵۰ دستور غذای سالم با جزئیات کامل (کالری، پروتئین، چربی، زمان پخت).
- **🛒 لیست خرید هوشمند:** امکان افزودن مواد اولیه به سبد خرید و اتصال به فروشگاه‌ها.
- **💪 چالش‌های ورزشی ۳۰ روزه:** برنامه‌های تمرینی متنوع برای چربی‌سوزی، فرم‌دهی و تسکین درد.
- **💆‍♀️ آموزش ماساژ:** آموزش‌های گام‌به‌گام ماساژ صورت و بدن با نکات ایمنی.
- **🤖 دستیار هوشمند (Nutribot):** پیشنهاد هوشمند وعده‌های غذایی و پاسخ به سوالات سلامتی.
- **🌙 حالت شب و روز:** رابط کاربری کاملاً واکنش‌گرا (Responsive) با قابلیت تغییر تم.

## 🛠 تکنولوژی‌های استفاده‌شده
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Hosting:** GitHub Pages
- **Design:** Mobile-First, Modern UI/UX
